稅費查核進度
資料來源：台灣虎航官網每日票價 API（api-book.tigerairtw.com/api/cms/station-daily-prices），涵蓋桃園／台中／高雄／台南出發的所有航點。 API 回傳未稅單程最低價，數值與官網「選擇航班」頁一致。
「稅金與其他費用」逐航段取自官網訂票引擎購物車明細；費用依實測基準及旅行日期計算；尚未實測的航段只顯示未稅價。
票價為 1 位成人、不含託運行李與選位；實際可售價格隨機位變動（實測一小時內就會變動），請以官網結帳頁為準。
